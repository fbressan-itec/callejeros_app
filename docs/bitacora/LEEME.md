## Reglas

- Una entrada **por sesión de trabajo**, agregada **al final** del archivo propio. No se borran ni se reescriben entradas viejas.
- Se escribe al terminar la sesión (la IA puede redactarla; el integrante la revisa).
- Se sube con el commit de la tarjeta o en uno aparte: `docs(bitacora): registra avance del <fecha>`.

## Formato de cada entrada

```markdown
## AAAA-MM-DD — <título corto>

- **Tarjeta:** #<n°> (<código de orden de trabajo, ej. BK-03>)
- **Rama:** feature/<épica>-<n°>-<nombre>
- **Área:** back / front / db / test / devops / docs
- **Qué hice:**
  - ...
- **Decisiones tomadas:** ... (y por qué)
- **Problemas y cómo los resolví:** ...
- **Pendiente:** ...
- **PR:** #<n°> (si ya se abrió)
- **IA usada:** Claude Code / Antigravity / ninguna — para qué
```
